🎯 Hangman: The Game
A classic word-guessing game built using Dart.
📌 Overview
Hangman: The Game is a console-based implementation of the traditional Hangman word game, developed in Dart. It challenges players to guess a hidden word one letter at a time before they run out of chances. This project serves as both a fun and educational demonstration of Dart's core programming features such as control structures, string manipulation, and list operations.
🧠 Game Rules
	A random word is selected from a predefined word list.
	The player has a fixed number of chances (typically 6–8) to guess the word.
	Each correct guess reveals all instances of the guessed letter in the word.
	Incorrect guesses reduce the remaining attempts.
	The game ends in either:
o	Victory: when the player correctly guesses all letters in the word.
o	Defeat: when the player runs out of attempts.
🚀 Features
	CLI-based interaction with clear prompts and messages.
	Tracks guessed letters to avoid repetition.
	Visual hangman scaffold representation (optional for text mode).
	Case-insensitive word checking.
	Easy to extend with categories or difficulty levels.
🛠️ Technologies Used
	Language: Dart
